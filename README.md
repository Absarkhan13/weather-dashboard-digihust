# 🌤️ Weather Dashboard

A modern, glassmorphism-styled weather dashboard built with **vanilla HTML, CSS, and JavaScript**. Fetches real-time weather data from the **OpenWeatherMap API** with a clean, responsive, and animated UI.

![Weather Dashboard Preview](preview.png)

---

## ✨ Features

- 🔍 **Search by city** — Get instant weather for any city worldwide
- 🌡️ **Real-time data** — Temperature, humidity, and wind speed
- 🎨 **Pro glassmorphism UI** — Smooth animations and modern design
- 💾 **Remembers last city** — Uses `localStorage` to restore your last search
- 📱 **Fully responsive** — Works perfectly on mobile, tablet, and desktop
- ⚠️ **Friendly error handling** — Clear messages for invalid cities
- ⚡ **Fast & lightweight** — No frameworks, no dependencies

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| CSS3 | Styling (Flexbox, Glassmorphism, Animations) |
| JavaScript (ES6+) | Logic (Async/Await, Fetch API, DOM) |
| OpenWeatherMap API | Weather data source |
| Font Awesome | Icons |
| Google Fonts (Inter) | Typography |
